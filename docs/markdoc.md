# ページの部品 (Markdoc)

atfedi-content の長文ページは Markdoc で表示します。Markdoc は CommonMark に「タグ」を足したものなので、ふつうの Markdown だけのページは、そのまま同じように表示されます。

## 使えるタグ

```
{% icon name="map" /%}
```
文中に Lucide のアイコンを置きます。`[icon:map]` と書いても同じです。

```
{% callout %}
ひとこと添えたいとき。
{% /callout %}

{% callout type="warning" %}
**取り消せません。** 消したあとは戻せません。
{% /callout %}
```
囲みです。`warning` は、取り消せないことの警告にだけ使います（STYLE.md の「太字は警告だけ」と同じ決まりです）。囲みの中の太字は、目次に載りません。

```
{% card %}
{% icon name="heart-handshake" /%} [題名](/build/fedify/feels-good) — ひとこと
{% /card %}
```
サブページへの入り口です。1 行で、アイコン、リンク、説明の順に書きます。`:::card … :::` も使えます。

```
{% cards %}
- {% icon name="map" /%} **題名** — 説明 — [リンク](https://example.org)
{% /cards %}
```
小さなカードの並びです。リスト 1 項目が 1 枚になります。`:::cards … :::` も使えます。

## 小さな表

```
| サーバー | 上限 |
|---|---|
| a | 500 |
```
ふつうの表の書き方で書けます。幅が足りないときは横にスクロールします。

## write / translate での扱い

`{% … %}` だけの行は、ひとつの段落として数えます。囲みの中の文章は、ふつうの段落と同じように、言語どうしで段落ごとに対応します。
